## Committee defense: data to action

1. **Input boundary:** `data/processed/prices.csv` contains monthly adjusted-price proxies through September 2026; `src/data.py` converts common monthly observations into arithmetic return estimates and sample covariance. The default 60-observation window is an analytical choice, not a forecast.
2. **One calculation to show:** In `src/engine.py`, a candidate portfolio's annual expected return is its weights multiplied by annual fund means. The constrained optimum is 77.04% BIL and 22.96% VT, with the model's annual mean at the illustrative 5.50% hurdle. `scripts/audit_finance.py` independently recomputes the same figure from CSV values without using the production estimator. Show this in the Portfolio construction tab and `outputs/audit-independent-finance.json`.
3. **Decision rule:** `src/workflow.py::stop_decision` collects failed and unknown rules. The constrained research candidate passes measured numerical rules, but actual holdings/costs, Cedar's numeric risk limit, BIL reserve acceptance, benchmark approval and the rolling real after-cost outcome remain Not Known. The app's authorization gate therefore fails and assigns 0% **new capital** to this process. This is a process authorization decision, not a direction to sell existing holdings.
4. **Sensitivity:** The already executed 36-month stress moves BIL from 77.04% to 92.86% (a 15.82 percentage-point move) while the draft deployment decision remains Reject. That checks allocation sensitivity; it is **not** the required student AI-off changed-input record. Explain any later genuine locked result only after its before/after files and prediction commit exist.
5. **Reversal:** Revisit only after the committee resolves the mandate interpretations, actual holdings/trading costs and signal admission, then reruns the model and stresses. A favorable solver output alone does not authorize a trade.
